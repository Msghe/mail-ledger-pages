Mail Ledger

A personal, self-hosted email bookkeeping tool.

Mail Ledger is a private, personal-use application that connects to a single user's own email account(s) (via Gmail API / Microsoft Graph) to read incoming messages and organize them into a local ledger/database for personal record-keeping, expense tracking, and daily digest generation.

This application is not publicly distributed, has no other users besides its owner/developer, and does not share, sell, or transmit any account data to third parties. All processed data is stored locally on infrastructure controlled by the application owner.

See our Privacy Policy for details on how data is accessed, used, and stored.
