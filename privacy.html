Privacy Policy

Last updated: 2026-09-16

Mail Ledger ("the application") is a personal-use, self-hosted tool built and operated by a single individual for their own private email organization needs. This Privacy Policy explains how the application accesses, uses, and stores data.

1. Scope of Use

The application is used exclusively by its owner/developer. It is not distributed publicly, has no other end users, and is not offered as a service to any third party.

2. Data Accessed

With explicit OAuth authorization from the account owner, the application reads email metadata and message content (via the Gmail API read-only scope and/or Microsoft Graph mail-read scope) from the owner's own email account(s) solely to organize messages into a local ledger for personal record-keeping.

3. Data Storage

All data retrieved from connected email accounts is stored locally in a private database controlled by the application owner. No data is uploaded to, shared with, or sold to any third-party service, advertiser, or data broker.

4. Data Use

Data is used only for the purpose of generating personal summaries, digests, and records for the account owner. The application does not use data for advertising, profiling, or any purpose unrelated to the owner's personal bookkeeping.

5. Data Sharing

No data collected by this application is shared with any third party.

6. Data Retention and Deletion

Data is retained locally for as long as the application owner chooses. The owner may delete all locally stored data and revoke the application's access to their email account(s) at any time via their Google Account or Microsoft Account security settings.

7. Google API Services User Data Policy

Mail Ledger's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Contact

For questions about this policy, contact the application owner via the support email listed on the associated OAuth consent screen.
